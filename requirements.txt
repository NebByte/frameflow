# What the toolkit and the agent need to run.
#
# This used to pin opencv and numpy only, while the code imported a good deal
# more -- fine on the machine it was written on and broken everywhere else.
#
# The heavy dependencies (torch, gsplat, diffusers) are deliberately NOT here.
# Every one of them is imported inside the function that needs it, so the CPU
# path -- which is the whole product -- installs and runs without a gigabyte of
# CUDA wheels. See requirements-gpu.txt for the 3D reconstruction path.

# --- the pipeline
opencv-python-headless>=4.9
numpy>=1.26

# --- the agent: ADK brings google-genai, which reaches Gemini on Vertex AI
google-adk>=2.8

# --- the ledger. Reads in the agent go through the official ClickHouse MCP
#     server (`uvx mcp-clickhouse`); this client is what writes the rows.
clickhouse-connect>=0.8

# The MCP SDK. NOT a dependency of google-adk, and it was installed on the
# development machine by something else -- so McpToolset built locally, failed
# silently in the container, and the archivist told users the ledger was not
# connected while /status said it was.
# Capped below 2.0. `mcp.shared.session` -- which google-adk's McpToolset
# imports -- was removed in the 2.x layout, so an unpinned install resolves to
# 2.1.1 and the toolset fails with ModuleNotFoundError. It imported fine on the
# dev machine because that had 1.27.0 already installed, so the break only
# appeared in the container.
mcp>=1.27,<2

# The ClickHouse MCP server itself, installed rather than fetched on demand.
# `uvx mcp-clickhouse` downloads the package the first time it runs, which
# takes far longer than ADK's 5-second session timeout -- so every ledger query
# failed with "timed out waiting for the session to become ready" while the
# toolset itself looked perfectly healthy.
mcp-clickhouse>=0.4

# --- serving. ADK already depends on fastapi and uvicorn; pinned here anyway
#     because server.py imports them directly and a transitive dependency is
#     not a promise.
fastapi>=0.115
uvicorn[standard]>=0.30
httpx>=0.27
